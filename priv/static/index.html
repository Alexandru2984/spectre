Public and ephemeral, with limits.

Choose a public room or create a private event. Messages are held in server memory until expiry or restart. Public rooms are open to everyone. Private rooms require an invitation; optional E2EE encrypts message and poll text in your browser. Room metadata and traffic remain visible to the server.

People can copy or screenshot a message. Infrastructure logs, browser memory and system memory may outlive its timer. Only appearance preferences are stored in your browser; message text and burn keys are not saved to browser storage. Reloading loses your burn controls.
