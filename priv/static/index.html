About Spectre

Public and private event rooms for messages, replies and polls. Messages expire within five minutes. Private events can encrypt message text in the browser.

How it works · Privacy and encryption

About Spectre

Open a room

Private invitations grant access to anyone holding the link. Encryption protects message and poll text; metadata remains visible to the server. Keep the invitation and owner key safe. Reloading loses unsaved controls.

Room settings

The interval applies to each open page. Hosts can always post. Room names and topics are visible to the server, including in encrypted rooms.

How Spectre works

  • Choose a room

    Use a public room or create an event and share its invitation.

  • Set an expiry

    Choose how long your message stays, from 15 seconds to 5 minutes.

  • Join the conversation

    Reply, react, vote in polls or delete your own messages.

Privacy and limits.

Choose a public room or create a private event. Messages are held in server memory until expiry or restart. Public rooms are open to everyone. Private rooms require an invitation; optional E2EE encrypts message and poll text in your browser. Room metadata and traffic remain visible to the server.

Messages can be copied or captured in screenshots. Infrastructure logs and browser or system memory may outlive the timer. Only display and language preferences are saved in browser storage; message text and creator keys stay in page memory. Reloading loses unsaved controls.
